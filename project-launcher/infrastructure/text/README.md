# 文本项目基础设施

## 目录结构

```
infrastructure/text/
├── academic/      — 学术写作（论文、研究报告）
├── creative/      — 创意写作（小说、剧本）
└── technical/     — 技术文档（API文档、设计文档）
```

## 质量标准

- **内容深度**：详细文档，内容充足
- **不搞空壳**：文档不搞空壳，即使工作已安排好也要有实质内容
- **实际展示**：包含实际的研究/调研结果，不是声称"存在"

## 学术写作规范

- 格式：IEEE / APA / Chicago / GB/T 7714
- 结构：摘要 → 引言 → 相关工作 → 方法 → 实验 → 结论
- 引用：所有引用必须有实际来源

## 创意写作规范

- 结构：大纲 → 角色设定 → 章节撰写
- 一致性：角色性格、世界观、时间线一致性
- 叙事：展示而非告知（Show, don't tell）

## 技术文档规范

- 结构：概述 → 安装 → 使用 → API → FAQ
- 代码示例：所有代码必须可运行
- 版本：标注适用的软件版本

## 知识获取

当写作主题缺少相关知识时：

1. WebSearch 搜索主题关键词 + 学术/技术来源
2. WebFetch 获取权威内容
3. 提取关键知识点存入 `knowledge/`
4. 生成参考资料索引
